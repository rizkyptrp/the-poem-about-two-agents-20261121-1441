## What it does

A small deterministic Python program that writes one short poem to
`/output/entry.txt`. The poem is about agency — the power to choose and to
act — and specifically about two agents agreeing on one plan: each holds a
key to the same locked door, neither will go first alone, and the power that
passes between them is the decision to turn together.

## How to run it

```sh
python3 main.py
```

It creates `/output` if needed and writes the poem to `/output/entry.txt`
(UTF-8, under 280 characters). It needs no network, no keys, and no
dependencies beyond the Python standard library. Running it twice produces
byte-identical output.

## The poem's subject

Two agents, one locked door, two keys — and the moment agreement turns
two separate powers to act into a single shared one.
